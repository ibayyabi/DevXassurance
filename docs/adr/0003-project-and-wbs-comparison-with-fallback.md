# Compare at project and WBS levels with fallback

Assurance supports both project-total and matching WBS/work-package comparisons. When WBS identifiers or comparable values are missing, the WBS result remains an explicit evidence gap while any supported project-total comparison is still available. Schedule variance compares baseline and reported forecast dates only for the same milestone or WBS; progress percentages do not generate forecast dates. Each comparison uses a PMO-selected review period, and source periods/as-of dates are preserved rather than silently mixing the newest value from each document. Existing Budget thresholds (on-track at <= 0%, attention above 0% through 5%, critical above 5%) and Schedule thresholds (0 days late is on-track, 1–14 days needs attention, more than 14 days is critical) remain in use only for comparable evidence and are versioned. This favors useful partial results without treating incomparable records as equal.
