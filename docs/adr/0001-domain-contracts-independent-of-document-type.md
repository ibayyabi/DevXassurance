# Domain contracts independent of document type

The pipeline uses two layers: document type describes an uploaded artifact, while evidence contracts describe PMO data domains. One source document may contribute to multiple domain contracts; document and section labels guide interpretation but do not gate extraction of clear evidence. Retain the existing document-level classifier; for each existing text group, one structured model call identifies relevant section/domain evidence and extracts all relevant contracts together, rather than adding a separate section-classification call, a call per domain, or sending an entire long document as one input. The provider and model are not selected yet; a free provider is preferred, and domain contracts remain provider-independent. If a provider quota is reached, defer/retry remaining groups when capacity returns; keep them marked not processed until handled, never as absent evidence. Each observation retains its original value and exact source location; safe normalization supplements rather than replaces the source value. A reviewer may correct the value used in assessment, but the original extraction and source evidence remain unchanged and the correction is attributed. This handles varied input templates and overlapping fields across baseline, finance, and WBS reports.
