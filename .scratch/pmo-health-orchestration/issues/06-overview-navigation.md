# 06: Overview progress dan navigasi tinjauan

**What to build:** PMO dapat melihat Progress, Budget, Schedule, dan Risk secara terpisah dan berpindah antar-cut-off dengan sumber serta gap yang jelas.

**Blocked by:** 04: Progress per komponen dan cut-off; 05: Perbandingan risk snapshot lintas waktu.

**Status:** ready-for-agent

Baca [rencana](../plan.md). Tidak ada composite score atau agregasi lintas scope tanpa keputusan domain baru.

- [ ] Overview menampilkan kondisi per domain, cut-off, perubahan yang valid, sumber, dan alasan gap; chart tidak mengubah gap menjadi nol/hijau.
- [ ] Pengguna dapat menavigasi tinjauan W4–W7 dan membedakan file bernama sama; periode yang tidak cocok atau tidak diketahui tidak tercampur diam-diam.
- [ ] Evidence parsial/warning terlihat; RAG yang dilaporkan sumber dibedakan dari kondisi hasil aturan sistem.
- [ ] Tampilan nyata diperiksa via browser untuk desktop/mobile, keyboard, focus, dan nama kontrol; simpan bukti verifikasi.
